問 1

2次関数 $y = x^{2}-6x+5$ のグラフの頂点の座標は ( ア , $-$イ ) である。

正解　③ 3

着眼点

頂点を求めるには平方完成が基本である。$x$ の係数 $-6$ の半分 $-3$ を作り、$(x-3)^{2}$ の形を目指す。

解法

$y = x^{2}-6x+5 = (x-3)^{2}-9+5 = (x-3)^{2}-4$。したがって頂点は $(3,\ -4)$ で、$x$ 座標は $3$。よってア＝3。

検算

$x = 3$ を元の式に代入すると $9-18+5 = -4$ となり、頂点の $y$ 座標と一致する。また $x=2$ と $x=4$ を代入するとどちらも $-3$ になり、$x=3$ を軸として左右対称であることが確かめられる。

つまずきやすい点

平方完成で引く数を忘れる誤りが多い。$(x-3)^{2}$ を展開すると $x^{2}-6x+9$ となり、元の式より $9$ だけ大きい。だから $-9$ を補って辻褄を合わせる。この $-9$ を落とすと頂点の $y$ 座標を間違える。

関連して押さえる

$y = ax^{2}+bx+c$ の頂点の $x$ 座標は $-\dfrac{b}{2a}$ である。この式に $a=1,\ b=-6$ を入れれば $3$ が直ちに出る。平方完成が面倒なときの近道として覚えておくとよい。

問 2

2次関数 $y = x^{2}-6x+5$ のグラフの頂点の座標は ( $3$ , $-$イ ) である。

正解　④ 4

着眼点

頂点の $x$ 座標が $3$ と分かっているので、そこでの $y$ の値を求めればよい。平方完成の定数項を読むか、$x=3$ を代入するかの二通りがある。

解法

$y = (x-3)^{2}-4$ と平方完成できるので、頂点は $(3,\ -4)$。$y$ 座標は $-4$ であり、問題文が $-$イ と符号を外に出しているので イ＝4。

検算

$x=3$ を元の式に直接代入すると $3^{2}-6\cdot 3+5 = 9-18+5 = -4$。平方完成の結果と一致する。

つまずきやすい点

問題文が $-$イ と書いているのに、イ に $-4$ を入れようとする誤りがある。符号はすでに問題文側にあるので、空欄には絶対値にあたる $4$ を入れる。マーク式では負の数をマークできないため、符号を外に出す書き方が使われる。

関連して押さえる

この関数は $x^{2}$ の係数が正なので下に凸であり、頂点で最小値をとる。すなわち最小値は $-4$、最大値は存在しない。頂点の $y$ 座標がそのまま最小値になるという対応を押さえておくこと。

問 3

2次関数 $y = x^{2}-6x+5$ のグラフは $x$ 軸と2点で交わる。
そのうち $x$ 座標が大きい方の点の $x$ 座標は ウ である。

正解　⑤ 5

着眼点

$x$ 軸との交点は $y=0$ となる点である。$x^{2}-6x+5=0$ を解けばよい。

解法

$x^{2}-6x+5 = (x-1)(x-5) = 0$ より $x = 1,\ 5$。大きい方は $5$ なのでウ＝5。

検算

解と係数の関係を使う。2解の和は $-\dfrac{-6}{1} = 6$、積は $\dfrac{5}{1} = 5$。$1+5 = 6$、$1 \times 5 = 5$ でどちらも合う。因数分解が正しかったことが確かめられる。

つまずきやすい点

$(x-1)(x-5)$ と $(x+1)(x+5)$ を取り違える誤りがある。展開したとき $x$ の係数が $-6$ になるのは、$-1$ と $-5$ を足した場合である。定数項 $+5$ だけを見て符号を決めると間違える。和と積の両方を確かめること。

関連して押さえる

2つの交点の $x$ 座標は $1$ と $5$ で、その中点は $\dfrac{1+5}{2} = 3$。これは頂点の $x$ 座標と一致する。放物線は軸に関して対称なので、$x$ 軸との2交点の中点は必ず軸の上に来る。この性質は交点の一方だけが分かっているときに使える。

問 4

2次関数 $y = -2x^{2}+8x-3$ のグラフの軸は直線 $x =$ エ である。

正解　② 2

着眼点

軸を求めるには、$x^{2}$ の係数でくくってから平方完成する。係数が $-2$ と負である点に注意する。

解法

$y = -2x^{2}+8x-3 = -2(x^{2}-4x)-3 = -2\{(x-2)^{2}-4\}-3 = -2(x-2)^{2}+8-3 = -2(x-2)^{2}+5$。したがって軸は $x = 2$ で、エ＝2。

検算

公式 $x = -\dfrac{b}{2a}$ に $a=-2,\ b=8$ を入れると $-\dfrac{8}{2 \times (-2)} = -\dfrac{8}{-4} = 2$。平方完成の結果と一致する。

つまずきやすい点

くくり出した $-2$ を戻すときの符号を誤りやすい。$-2\{(x-2)^{2}-4\}$ の中の $-4$ に $-2$ を掛けると $+8$ になる。この符号変化を見落とすと定数項がずれる。中かっこの外し方を丁寧に書くこと。

関連して押さえる

軸の位置は $x^{2}$ の係数の符号に影響されない。$y = 2x^{2}-8x-3$ でも軸は $x=2$ である。符号が変わると上に凸か下に凸かが変わるだけで、左右の位置は変わらない。

問 5

2次関数 $y = -2x^{2}+8x-3$ の最大値は オ である。

正解　⑤ 5

着眼点

$x^{2}$ の係数が $-2$ で負なので、このグラフは上に凸である。上に凸の放物線は頂点で最大値をとる。

解法

平方完成すると $y = -2(x-2)^{2}+5$。$(x-2)^{2} \geqq 0$ なので $-2(x-2)^{2} \leqq 0$ であり、$y$ は $x=2$ のとき最大値 $5$ をとる。よってオ＝5。

検算

$x=2$ を元の式に代入すると $-2 \times 4 + 8 \times 2 - 3 = -8+16-3 = 5$。また $x=1$ では $-2+8-3 = 3$、$x=3$ では $-18+24-3 = 3$ となり、どちらも $5$ より小さい。$x=2$ が最大を与えることが確かめられる。

つまずきやすい点

上に凸か下に凸かを確かめずに「頂点は最小値」と決めつける誤りが最も多い。判断の基準は $x^{2}$ の係数の符号だけである。正なら下に凸で最小値、負なら上に凸で最大値。この一点を先に確認する習慣をつけること。

関連して押さえる

この関数に最小値は存在しない。上に凸の放物線は $x$ を大きくしても小さくしても $y$ が限りなく小さくなるからである。定義域に制限がない2次関数は、最大値と最小値のどちらか一方しか持たない。

問 6

2次関数 $y = -2x^{2}+8x-3$ の $0 \leqq x \leqq 3$ における最小値は $-$カ である。

正解　③ 3

着眼点

定義域が区切られている場合、最小値の候補は区間の両端と頂点の3か所に限られる。この3点だけを調べればよい。

解法

$y = -2(x-2)^{2}+5$ で頂点は $x=2$、これは $0 \leqq x \leqq 3$ の中にある。3点の値を求めると、$x=0$ のとき $-3$、$x=2$ のとき $5$、$x=3$ のとき $-18+24-3 = 3$。最小は $-3$ なので、$-$カ より カ＝3。

検算

上に凸のグラフでは、頂点から遠い端ほど値が小さい。頂点 $x=2$ からの距離は、$x=0$ が $2$、$x=3$ が $1$ である。遠い $x=0$ の側が最小になるはずで、実際に $-3 < 3$ となっており矛盾しない。

つまずきやすい点

頂点が定義域に含まれるからといって、そこが最小値だと思い込む誤りがある。上に凸なので頂点は最大値であり、最小値は端点で生じる。凸の向きと、求めるのが最大か最小かの組み合わせで、どこを見るべきかが変わる。

関連して押さえる

定義域つきの2次関数では4通りの型がある。下に凸で最小を問うなら頂点が定義域内かどうかで場合分け、下に凸で最大を問うなら軸から遠い端点、上に凸ならその逆。「軸から遠いほど頂点と反対の値になる」と覚えておけば、すべて同じ考え方で処理できる。

問 7

2次関数 $y = x^{2}+ax+b$ のグラフが2点 $(1,\ 0)$、$(3,\ 0)$ を通るとき、
$a = -$キ である。

正解　④ 4

着眼点

$(1,0)$ と $(3,0)$ を通るとは、$x=1$ と $x=3$ が $x^{2}+ax+b=0$ の解だということ。因数分解した形が直ちに書ける。

解法

2解が $1$ と $3$ で $x^{2}$ の係数が $1$ だから、$x^{2}+ax+b = (x-1)(x-3) = x^{2}-4x+3$。係数を比べて $a = -4$。問題文が $-$キ としているのでキ＝4。

検算

解と係数の関係で確かめる。2解の和は $-a$ に等しいので $1+3 = 4 = -a$ より $a=-4$。因数分解の結果と一致する。

つまずきやすい点

$(x-1)(x-3)$ とすべきところを $(x+1)(x+3)$ としてしまう誤りが多い。$x=1$ を代入して $0$ になるのは $(x-1)$ の方である。「解が $1$ なら因数は $x-1$」と、符号が反転することを意識すること。

関連して押さえる

$x^{2}$ の係数が $1$ でない場合は $y = k(x-1)(x-3)$ と未知の定数を置く。通る点がもう一つ与えられれば $k$ が決まる。2点だけでは放物線は一つに定まらず、$x$ 軸との交点2つに加えてもう一つ条件が要る。

問 8

2次関数 $y = x^{2}+ax+b$ のグラフが2点 $(1,\ 0)$、$(3,\ 0)$ を通るとき、
$b =$ ク である。

正解　③ 3

着眼点

前問と同じく $(x-1)(x-3)$ の展開から読み取る。$b$ は定数項である。

解法

$(x-1)(x-3) = x^{2}-4x+3$ より $b = 3$。よってク＝3。

検算

解と係数の関係では、2解の積が $b$ に等しい。$1 \times 3 = 3$ となり一致する。また $x=1$ を $y = x^{2}-4x+3$ に代入すると $1-4+3 = 0$、$x=3$ では $9-12+3 = 0$ で、どちらも $x$ 軸上にある。

つまずきやすい点

定数項 $b$ は $y$ 軸との交点の $y$ 座標でもある。$x=0$ を代入すれば $y=b$ になるからである。この対応を知らないと、グラフから $b$ を読み取る問題で手が止まる。

関連して押さえる

$y = x^{2}-4x+3$ を平方完成すると $(x-2)^{2}-1$ で、頂点は $(2,\ -1)$。$x$ 軸との交点 $1$ と $3$ の中点が $2$ であり、軸の位置と一致している。交点・軸・頂点の三つは常に連動している。

問 9

2次関数 $y = x^{2}+6x+k$ の最小値が $-4$ であるとき、$k =$ ケ である。

正解　⑤ 5

着眼点

下に凸の2次関数の最小値は頂点の $y$ 座標である。まず平方完成して頂点を $k$ で表す。

解法

$y = x^{2}+6x+k = (x+3)^{2}-9+k$。最小値は $x=-3$ のときの $k-9$ である。これが $-4$ に等しいので $k-9 = -4$、よって $k = 5$。ケ＝5。

検算

$k=5$ として $y = x^{2}+6x+5$ に $x=-3$ を代入すると $9-18+5 = -4$。最小値が $-4$ になることが確かめられる。

つまずきやすい点

平方完成で生じる $-9$ を忘れ、$k = -4$ としてしまう誤りが多い。$(x+3)^{2}$ を展開すると $x^{2}+6x+9$ となり、余分な $+9$ が出る。これを打ち消す $-9$ が定数項に残ることを見落とさないこと。

関連して押さえる

最小値が負であることから、このグラフは $x$ 軸と2点で交わると分かる。判別式で確かめると $D = 36-4 \times 5 = 16 > 0$ で一致する。頂点の $y$ 座標の符号と、$x$ 軸との交点の個数は連動している。

問 10

2次関数 $y = x^{2}+6x+5$ のグラフが $x$ 軸と交わる2点の間の距離は コ である。

正解　④ 4

着眼点

$x$ 軸との交点を求め、その差を取る。2点はどちらも $x$ 軸上にあるので、距離は $x$ 座標の差の絶対値になる。

解法

$x^{2}+6x+5 = (x+1)(x+5) = 0$ より $x = -1,\ -5$。距離は $-1-(-5) = 4$。よってコ＝4。

検算

平方完成した $y = (x+3)^{2}-4$ を使うと、$(x+3)^{2} = 4$ より $x+3 = \pm 2$、すなわち $x = -1,\ -5$。頂点 $x=-3$ から左右に $2$ ずつ離れており、距離は $2 \times 2 = 4$ である。因数分解と同じ結果になる。

つまずきやすい点

$-1$ と $-5$ の差を $-1-5 = -6$ と計算する誤りがある。差を取るときは小さい方を引くので $-1-(-5) = -1+5 = 4$ である。負の数の引き算では符号が反転することに注意する。

関連して押さえる

2交点間の距離は $\dfrac{\sqrt{D}}{|a|}$ で求められる。ここで $D$ は判別式である。$D = 36-20 = 16$、$|a| = 1$ なので $\dfrac{\sqrt{16}}{1} = 4$ となり一致する。解を求めずに距離だけを出したいときに使える公式である。
