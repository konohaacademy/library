問 1

$(2x+3)(x-5)$ を展開すると $2x^{2}-$ア$x-15$ となる。

正解　⑦ 7

着眼点

展開して $x$ の項だけを集めればよい。定数項 $-15$ はすでに与えられているので、途中の計算が合っているかの手がかりになる。

解法

$(2x+3)(x-5) = 2x\cdot x + 2x\cdot(-5) + 3\cdot x + 3\cdot(-5) = 2x^{2}-10x+3x-15 = 2x^{2}-7x-15$。したがって $-$ア$x = -7x$ となり、ア＝7。

検算

$x$ に $1$ を代入して確かめる。左辺は $(2+3)(1-5) = 5\times(-4) = -20$。右辺は $2-7-15 = -20$。一致するので正しい。

つまずきやすい点

符号の扱いで落とす人が多い。問題文が $2x^{2}-$ア$x$ と書いているので、アに入るのは $-7$ ではなく $7$ である。空欄の直前にある符号まで含めて読むこと。

関連して押さえる

2次式の展開は $(ax+b)(cx+d) = acx^{2}+(ad+bc)x+bd$。$x$ の係数は「たすきがけ」の形 $ad+bc$ になる。ここでは $2\cdot(-5)+3\cdot 1 = -7$ と一発で出せる。

問 2

$6x^{2}+$イ$x-6$ を因数分解すると $(2x+3)(3x-2)$ となる。

正解　⑤ 5

着眼点

因数分解の結果が与えられているので、それを展開し直して $x$ の係数を読めばよい。因数分解そのものを一から探す必要はない。

解法

$(2x+3)(3x-2) = 6x^{2}-4x+9x-6 = 6x^{2}+5x-6$。したがってイ＝5。

検算

$x$ に $1$ を代入する。左辺は $6+5-6 = 5$。右辺は $(2+3)(3-2) = 5\times 1 = 5$。一致する。

つまずきやすい点

$-4x$ と $+9x$ を足すとき、符号を見誤って $-5$ としてしまう誤りが多い。外側どうしの積 $2x\cdot(-2) = -4x$、内側どうしの積 $3\cdot 3x = 9x$ を分けて書き出すと防げる。

関連して押さえる

たすきがけは、左の列に $2$ と $3$、右の列に $3$ と $-2$ を置き、斜めに掛けて足すと $x$ の係数が出る。$2\times(-2)+3\times 3 = 5$。定数項は $3\times(-2) = -6$、$x^{2}$ の係数は $2\times 3 = 6$ で合う。

問 3

$x^{2}-10x+16$ を因数分解すると $(x-2)(x-$ウ$)$ となる。

正解　⑧ 8

着眼点

足して $10$、掛けて $16$ になる2数を探す。一方が $2$ と与えられているので、もう一方は積か和のどちらかから即座に決まる。

解法

$(x-2)(x-$ウ$) = x^{2}-(2+$ウ$)x+2\cdot$ウ。$x$ の係数を比べて $2+$ウ$=10$ より ウ＝8。定数項でも $2\cdot$ウ$=16$ より ウ＝8 となり一致する。

検算

$(x-2)(x-8) = x^{2}-8x-2x+16 = x^{2}-10x+16$。もとの式に戻るので正しい。

つまずきやすい点

係数を比べるとき、$x$ の項が $-(2+$ウ$)x$ であることを忘れて $2+$ウ$=-10$ としてしまう誤りがある。展開の形を一度書き下してから比べると確実。

関連して押さえる

$x^{2}+px+q = (x-\alpha)(x-\beta)$ のとき、$\alpha+\beta = -p$、$\alpha\beta = q$。これは2次方程式の解と係数の関係そのもので、因数分解と方程式の解は同じ内容を別の言い方で述べたものである。

問 4

$\sqrt{12-6\sqrt{3}}$ を簡単にすると エ$-\sqrt{3}$ となる。

正解　③ 3

着眼点

根号の中を $(a-b)^{2}$ の形に変形できないかを試す。二重根号は中身が平方になれば外れる。

解法

中の $6\sqrt{3}$ を $2\times 3\times\sqrt{3}$ と見る。すると $12-6\sqrt{3} = 9-2\cdot 3\cdot\sqrt{3}+3 = 3^{2}-2\cdot 3\cdot\sqrt{3}+(\sqrt{3})^{2} = (3-\sqrt{3})^{2}$。よって $\sqrt{12-6\sqrt{3}} = |3-\sqrt{3}|$ であり、$3 > \sqrt{3}$ なので $3-\sqrt{3}$。したがってエ＝3。

検算

おおよその値で確かめる。$\sqrt{3} \fallingdotseq 1.73$ なので $12-6\times 1.73 = 1.62$、その平方根は約 $1.27$。一方 $3-1.73 = 1.27$。一致する。

つまずきやすい点

$(3-\sqrt{3})^{2}$ の平方根を $3-\sqrt{3}$ と機械的に書いてよいのは、$3-\sqrt{3}$ が正のときだけである。もし $\sqrt{3}-3$ のように負になる形なら、絶対値を外すときに符号が反転する。必ず大小を確かめること。

関連して押さえる

二重根号 $\sqrt{a \pm 2\sqrt{b}}$ は、足して $a$、掛けて $b$ になる2数 $p,\ q$ を見つけて $\sqrt{p} \pm \sqrt{q}$ と外す。この問題では $6\sqrt{3} = 2\sqrt{27}$ と直せば、足して $12$、掛けて $27$ の組 $9$ と $3$ が見え、$\sqrt{9}-\sqrt{3} = 3-\sqrt{3}$ と求まる。

問 5

$x = 3+2\sqrt{2}$ のとき、$x+\dfrac{1}{x}$ の値は オ である。

正解　⑥ 6

着眼点

$\dfrac{1}{x}$ を有理化すれば、無理数の部分が打ち消し合うかどうかが見える。分母の $3+2\sqrt{2}$ に対し $3-2\sqrt{2}$ を掛けるのが定石。

解法

$\dfrac{1}{x} = \dfrac{1}{3+2\sqrt{2}} = \dfrac{3-2\sqrt{2}}{(3+2\sqrt{2})(3-2\sqrt{2})} = \dfrac{3-2\sqrt{2}}{9-8} = 3-2\sqrt{2}$。したがって $x+\dfrac{1}{x} = (3+2\sqrt{2})+(3-2\sqrt{2}) = 6$。よってオ＝6。

検算

$\sqrt{2} \fallingdotseq 1.414$ とすると $x \fallingdotseq 5.828$、$\dfrac{1}{x} \fallingdotseq 0.172$。足すと約 $6.00$ で一致する。

つまずきやすい点

分母の有理化で $(3+2\sqrt{2})(3-2\sqrt{2}) = 9-4\cdot 2 = 1$ となる計算を、$9-2 = 7$ などと誤りやすい。$(2\sqrt{2})^{2} = 4\times 2 = 8$ であることを丁寧に確かめること。

関連して押さえる

$x = 3+2\sqrt{2}$ は $x^{2}-6x+1 = 0$ の解である。この式の両辺を $x$ で割ると $x-6+\dfrac{1}{x} = 0$、すなわち $x+\dfrac{1}{x} = 6$ が直ちに得られる。有理化せずに求める道もある。

問 6

$x = 3+2\sqrt{2}$ のとき、$x^{2}+\dfrac{1}{x^{2}}$ の値は カキ である。

正解　③ 3

着眼点

$x^{2}$ と $\dfrac{1}{x^{2}}$ を別々に計算するのではなく、$x+\dfrac{1}{x}$ の値を利用する。2乗の展開で相殺が起こる。

解法

前問より $x+\dfrac{1}{x} = 6$。両辺を2乗すると $\left(x+\dfrac{1}{x}\right)^{2} = x^{2}+2\cdot x\cdot\dfrac{1}{x}+\dfrac{1}{x^{2}} = x^{2}+2+\dfrac{1}{x^{2}}$。よって $x^{2}+\dfrac{1}{x^{2}} = 6^{2}-2 = 34$。カキ＝34 なので、十の位のカ＝3。

検算

直接計算しても確かめられる。$x^{2} = (3+2\sqrt{2})^{2} = 9+12\sqrt{2}+8 = 17+12\sqrt{2}$、$\dfrac{1}{x^{2}} = (3-2\sqrt{2})^{2} = 17-12\sqrt{2}$。足すと $34$ で一致する。

つまずきやすい点

$\left(x+\dfrac{1}{x}\right)^{2}$ を展開したとき、真ん中の項が $2$ になることを見落として $x^{2}+\dfrac{1}{x^{2}} = 36$ としてしまう誤りが多い。$x\cdot\dfrac{1}{x} = 1$ なので中央の項は $2\times 1 = 2$ である。

関連して押さえる

対称式は基本対称式で表せる。$x+\dfrac{1}{x} = s$ とおくと $x^{2}+\dfrac{1}{x^{2}} = s^{2}-2$、$x^{3}+\dfrac{1}{x^{3}} = s^{3}-3s$ となる。$s$ さえ求めれば次数の高い式も芋づる式に出る。

問 7

$x = 3+2\sqrt{2}$ のとき、$x^{2}+\dfrac{1}{x^{2}}$ の値は $3$キ である。

正解　④ 4

着眼点

前問と同じ計算の一の位を答える。$x+\dfrac{1}{x} = 6$ から $x^{2}+\dfrac{1}{x^{2}} = 6^{2}-2$ を求める流れは変わらない。

解法

$x^{2}+\dfrac{1}{x^{2}} = \left(x+\dfrac{1}{x}\right)^{2}-2 = 36-2 = 34$。十の位が $3$、一の位が $4$ なので キ＝4。

検算

$x^{2} = 17+12\sqrt{2}$、$\dfrac{1}{x^{2}} = 17-12\sqrt{2}$ を直接足すと $34$。$\sqrt{2}$ の項が打ち消し合って整数になる点も、答えが整数であることの裏づけになる。

つまずきやすい点

$36-2$ を $36-4$ と誤る例がある。引くのは $2\cdot x\cdot\dfrac{1}{x}$ の $2$ であって、2乗した値ではない。展開の各項を書き出して確かめること。

関連して押さえる

$x^{2}+\dfrac{1}{x^{2}}$ が整数になるのは、$x$ と $\dfrac{1}{x}$ が互いに共役な無理数だからである。$3+2\sqrt{2}$ と $3-2\sqrt{2}$ のように、無理数の部分の符号だけが違う2数を共役といい、和と積はともに有理数になる。

問 8

2つの実数 $a,\ b$ が $a+b=5$、$ab=3$ を満たすとき、
$a^{2}+b^{2}$ の値は クケ である。

正解　① 1

着眼点

$a$ と $b$ の値を個別に求める必要はない。$a^{2}+b^{2}$ は和と積だけで表せる。

解法

$(a+b)^{2} = a^{2}+2ab+b^{2}$ だから、$a^{2}+b^{2} = (a+b)^{2}-2ab = 5^{2}-2\times 3 = 25-6 = 19$。クケ＝19 なので、十の位のク＝1。

検算

$a,\ b$ は $t^{2}-5t+3 = 0$ の2解で、$t = \dfrac{5 \pm \sqrt{13}}{2}$。それぞれ2乗して足すと $\dfrac{(25+10\sqrt{13}+13)+(25-10\sqrt{13}+13)}{4} = \dfrac{76}{4} = 19$。一致する。

つまずきやすい点

$a^{2}+b^{2} = (a+b)^{2}-ab$ と、$2$ を掛け忘れる誤りが目立つ。展開の中央の項は $2ab$ なので、引くのも $2ab$ である。

関連して押さえる

$a+b$ と $ab$ を基本対称式という。$a^{2}+b^{2} = (a+b)^{2}-2ab$、$a^{3}+b^{3} = (a+b)^{3}-3ab(a+b)$、$(a-b)^{2} = (a+b)^{2}-4ab$。どれも基本対称式だけで書けるので、個々の値を求めずに済む。

問 9

2つの実数 $a,\ b$ が $a+b=5$、$ab=3$ を満たすとき、
$a^{2}+b^{2}$ の値は $1$ケ である。

正解　⑨ 9

着眼点

前問と同じ式の一の位を答える。$a^{2}+b^{2} = (a+b)^{2}-2ab$ を使う流れは変わらない。

解法

$a^{2}+b^{2} = 5^{2}-2\times 3 = 25-6 = 19$。十の位が $1$、一の位が $9$ なので ケ＝9。

検算

$a+b = 5$、$ab = 3$ より $(a-b)^{2} = (a+b)^{2}-4ab = 25-12 = 13$。$a^{2}+b^{2} = \dfrac{(a+b)^{2}+(a-b)^{2}}{2} = \dfrac{25+13}{2} = 19$ となり、別の道からも同じ値が出る。

つまずきやすい点

$25-6$ の引き算そのものより、$2ab$ を $2\times 3 = 6$ と正しく計算できるかで差がつく。$ab = 3$ をそのまま引いて $22$ としてしまう誤りに注意。

関連して押さえる

$a^{2}+b^{2} \geqq 2ab$ は相加平均と相乗平均の関係から従う。ここでも $19 \geqq 6$ が成り立っている。答えが出たあとに不等式で妥当性を眺める習慣をつけると、大きな計算違いに気づける。

問 10

整式 $x^{3}-2x^{2}+3x-4$ を $x-2$ で割ったときの余りは コ である。

正解　② 2

着眼点

1次式で割った余りを問われているので、実際に割り算をせず剰余定理を使う。余りは定数になる。

解法

$f(x) = x^{3}-2x^{2}+3x-4$ とおく。$x-2$ で割った余りは $f(2)$ である。$f(2) = 8-2\times 4+3\times 2-4 = 8-8+6-4 = 2$。よってコ＝2。

検算

実際に割ると $x^{3}-2x^{2}+3x-4 = (x-2)(x^{2}+3)+2$ となる。展開すると $x^{3}+3x-2x^{2}-6+2 = x^{3}-2x^{2}+3x-4$ でもとに戻る。

つまずきやすい点

$x-2$ で割るときに代入するのは $x = 2$ であって $x = -2$ ではない。$x-a$ で割った余りが $f(a)$ であり、割る式を $0$ にする値を代入すると覚えるとよい。

関連して押さえる

余りが $0$ のとき、すなわち $f(a) = 0$ のとき $x-a$ は $f(x)$ を割り切る。これが因数定理で、高次方程式を解く際にまず整数の解を探すのはこの定理を使うためである。
