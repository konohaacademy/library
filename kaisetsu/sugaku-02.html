問 1

不等式 $3x-7 < 5x+1$ を解くと $x > -$ア である。

正解　④ 4

着眼点

$x$ を含む項を一方に、定数を他方に集める。負の数で割るときに不等号の向きが変わる点だけ気をつければ、1次方程式と同じ手順で解ける。

解法

$3x-7 < 5x+1$ の両辺から $5x$ を引き、$7$ を足すと $3x-5x < 1+7$、すなわち $-2x < 8$。両辺を $-2$ で割ると不等号の向きが変わり $x > -4$。よってア＝4。

検算

境界の $x = -4$ を代入すると左辺は $-12-7 = -19$、右辺は $-20+1 = -19$ で等しい。境界より大きい $x = 0$ では左辺 $-7$、右辺 $1$ で確かに左辺が小さい。向きは正しい。

つまずきやすい点

負の数で割るときに不等号を反転し忘れる誤りが最も多い。反転が不安なら、$x$ の項を正の側に集めて $8 > 2x$ としてから $4 > x$ と直す道もある。この形なら割る数が正なので向きは変わらない。

関連して押さえる

不等式で向きが変わるのは、負の数を掛けるときと負の数で割るときだけである。両辺に同じ数を足す・引く操作では向きは変わらない。この区別を徹底すれば符号の事故は起きない。

問 2

連立不等式 $\ 2x+3 \geqq x-2\ $ かつ $\ 3x-2 < x+6\ $ を解くと
$-$イ$\ \leqq x < 4$ である。

正解　⑤ 5

着眼点

連立不等式はそれぞれを別々に解き、最後に共通部分をとる。この問題では左側の境界を問われているので、1つ目の不等式だけで決まる。

解法

$2x+3 \geqq x-2$ より $2x-x \geqq -2-3$、すなわち $x \geqq -5$。もう一方の $3x-2 < x+6$ は $2x < 8$ より $x < 4$。共通部分は $-5 \leqq x < 4$ なので イ＝5。

検算

$x = -5$ は1つ目に等号で入り、2つ目は $-17 < 1$ で成り立つ。$x = -6$ は1つ目が $-9 \geqq -8$ となって成り立たない。境界は確かに $-5$ である。

つまずきやすい点

2つの解の範囲を数直線に書かずに頭の中で合わせようとすると、共通部分と和集合を取り違えやすい。「かつ」は重なった部分、「または」は合わせた部分である。必ず数直線を書くこと。

関連して押さえる

等号の有無は答えの書き方に直結する。1つ目は $\geqq$ なので $-5$ を含み、2つ目は $<$ なので $4$ を含まない。境界の値がそれぞれの不等式を満たすかを代入して確かめる習慣をつけるとよい。

問 3

連立不等式 $\ 2x+3 \geqq x-2\ $ かつ $\ 3x-2 < x+6\ $ を
満たす整数 $x$ は全部で ウ 個ある。

正解　⑨ 9

着眼点

前問で範囲は $-5 \leqq x < 4$ と分かっている。あとは端を含むかどうかを見て整数を数え上げるだけである。

解法

$-5 \leqq x < 4$ に入る整数は $-5,\ -4,\ -3,\ -2,\ -1,\ 0,\ 1,\ 2,\ 3$ の9個。よってウ＝9。

検算

個数は「大きい端 $-$ 小さい端 $+1$」で数えられる。ここでは含まれる整数の最小が $-5$、最大が $3$ なので $3-(-5)+1 = 9$。数え上げと一致する。

つまずきやすい点

$0$ を数え忘れる誤りが非常に多い。負の数から正の数へまたぐ範囲では、$0$ も1つの整数として必ず数えること。また $4$ は含まれない点にも注意する。

関連して押さえる

$a \leqq x \leqq b$ に含まれる整数の個数は $b-a+1$ 個（$a,\ b$ が整数のとき）。端が含まれない場合は、まず含まれる整数の最小と最大を確定させてからこの式を使うと間違えない。

問 4

方程式 $|x-3| = 5$ の解は $x = 8$ と $x = -$エ である。

正解　② 2

着眼点

絶対値が $5$ ということは、中身が $5$ か $-5$ のどちらかである。場合分けというより、2通りの方程式を並べて解けばよい。

解法

$x-3 = 5$ より $x = 8$。$x-3 = -5$ より $x = -2$。よって解は $x = 8,\ -2$ であり、エ＝2。

検算

$x = -2$ のとき $|-2-3| = |-5| = 5$ で成り立つ。$x = 8$ のとき $|8-3| = 5$ で成り立つ。両方とも確かに解である。

つまずきやすい点

$|x-3| = 5$ を $x-3 = 5$ だけで済ませ、負の側の解を落とす誤りが多い。絶対値の方程式は原則として解が2つ出ると身構えておくとよい。

関連して押さえる

$|x-a|$ は数直線上で $x$ と $a$ の距離を表す。この問題は「$3$ から距離 $5$ の点」を問うているので、$3$ の右に $5$ 進んだ $8$ と、左に $5$ 進んだ $-2$ が答えになる。図で捉えると場合分けが要らない。

問 5

不等式 $|2x-1| < 7$ を解くと $-3 < x <$ オ である。

正解　④ 4

着眼点

絶対値が $7$ より小さいということは、中身が $-7$ と $7$ の間にあるということ。不等式を2つに分けず、はさむ形で一気に書ける。

解法

$|2x-1| < 7$ は $-7 < 2x-1 < 7$ と同じ。各辺に $1$ を足して $-6 < 2x < 8$、$2$ で割って $-3 < x < 4$。よってオ＝4。

検算

$x = 4$ のとき $|8-1| = 7$ でちょうど等号になり、範囲の外側の境界であることが確かめられる。範囲内の $x = 0$ では $|-1| = 1 < 7$ で成り立つ。

つまずきやすい点

$|A| < c$ を $A < c$ だけで処理して負側を落とす誤りが目立つ。逆に $|A| > c$ のときは $A > c$ または $A < -c$ となり、はさむ形にはならない。不等号の向きで扱いが変わることを意識すること。

関連して押さえる

$|A| < c$（$c > 0$）は $-c < A < c$、$|A| > c$ は $A < -c$ または $A > c$。前者は1つの区間、後者は2つに分かれた範囲になる。数直線で「原点からの距離が $c$ より近いか遠いか」と考えると覚えやすい。

問 6

不等式 $|x+1| \geqq 7$ を解くと $x \leqq -8$ または $x \geqq$ カ である。

正解　⑥ 6

着眼点

絶対値が $7$ 以上ということは、中身が $7$ 以上か $-7$ 以下かのどちらかである。前問と違い、範囲は2つに分かれる。

解法

$x+1 \geqq 7$ より $x \geqq 6$。$x+1 \leqq -7$ より $x \leqq -8$。よって解は $x \leqq -8$ または $x \geqq 6$ であり、カ＝6。

検算

$x = 6$ のとき $|7| = 7$ でちょうど等号。$x = -8$ のとき $|-7| = 7$ でこちらも等号。二つの境界がともに条件を満たすので、等号つきの範囲として正しい。

つまずきやすい点

2つの範囲を「かつ」で結んでしまう誤りがある。$x \leqq -8$ かつ $x \geqq 6$ を満たす数は存在しない。絶対値が大きいという条件は「原点から遠い」ことなので、答えは離れた2方向になる。「または」で結ぶこと。

関連して押さえる

$|x+1|$ は $x$ と $-1$ の距離である。この問題は「$-1$ から距離 $7$ 以上の点」を問うており、$-1$ の右に $7$ 進んだ $6$ 以上と、左に $7$ 進んだ $-8$ 以下が答えになる。中心が $-1$ である点に注意する。

問 7

方程式 $|x-1|+|x-4| = 9$ の2つの解のうち、大きい方は $x =$ キ である。

正解　⑦ 7

着眼点

絶対値が2つあるので、中身の符号が変わる $x = 1$ と $x = 4$ で場合を分ける。大きい方の解を問われているので、$x \geqq 4$ の場合から調べればよい。

解法

$x \geqq 4$ のとき両方の中身が $0$ 以上なので $(x-1)+(x-4) = 2x-5 = 9$ より $x = 7$。これは $x \geqq 4$ を満たすので解である。よってキ＝7。

検算

$x = 7$ のとき $|7-1|+|7-4| = 6+3 = 9$ で成り立つ。

つまずきやすい点

場合分けして得た値が、その場合の範囲に入っているかを確かめずに答えとしてしまう誤りが多い。$1 \leqq x < 4$ の場合は $(x-1)+(4-x) = 3$ となり $9$ にはならないので、この範囲に解は無い。範囲の確認は必ず行うこと。

関連して押さえる

$|x-1|+|x-4|$ は、数直線上で $x$ から $1$ までの距離と $4$ までの距離の和を表す。$1$ と $4$ の間では常に $3$ で一定、外側では離れるほど大きくなる。この見方をすると、和が $9$ になる点が $1$ と $4$ の外側に1つずつあることが図で分かる。

問 8

方程式 $|x-1|+|x-4| = 9$ の2つの解のうち、小さい方は $x = -$ク である。

正解　② 2

着眼点

小さい方の解を求めるので、両方の絶対値の中身が負になる $x < 1$ の場合を調べる。

解法

$x < 1$ のとき $x-1 < 0$、$x-4 < 0$ なので、$|x-1| = 1-x$、$|x-4| = 4-x$。したがって $(1-x)+(4-x) = 5-2x = 9$ より $-2x = 4$、$x = -2$。これは $x < 1$ を満たすので解である。よってク＝2。

検算

$x = -2$ のとき $|-2-1|+|-2-4| = 3+6 = 9$ で成り立つ。

つまずきやすい点

中身が負のときに絶対値を外すと符号が反転する。$|x-1|$ を $x < 1$ のとき $1-x$ とせず $x-1$ のままにしてしまう誤りが最も多い。「負のものにマイナスを掛けて正にする」と考えれば $-(x-1) = 1-x$ と導ける。

関連して押さえる

2つの解 $x = 7$ と $x = -2$ は、$1$ と $4$ の中点である $2.5$ について対称な位置にある。$7-2.5 = 4.5$、$2.5-(-2) = 4.5$ で確かに等しい。距離の和という見方をすると、この対称性は当然の結果である。

問 9

不等式 $|x-2| \leqq 3$ を満たす整数 $x$ は全部で ケ 個ある。

正解　⑦ 7

着眼点

まず不等式を解いて $x$ の範囲を出し、そのうえで整数を数える。等号を含むので端の値も数に入る。

解法

$|x-2| \leqq 3$ は $-3 \leqq x-2 \leqq 3$ と同じ。各辺に $2$ を足して $-1 \leqq x \leqq 5$。この範囲の整数は $-1,\ 0,\ 1,\ 2,\ 3,\ 4,\ 5$ の7個なので ケ＝7。

検算

個数の式 $5-(-1)+1 = 7$ で一致する。両端の $x = -1$ と $x = 5$ はいずれも $|x-2| = 3$ となり、等号で条件を満たす。

つまずきやすい点

等号の有無で個数が変わる。もし $|x-2| < 3$ なら $-1 < x < 5$ となり、整数は $0$ から $4$ までの5個に減る。不等号に等号が付いているかを最初に確認すること。

関連して押さえる

$|x-a| \leqq r$ は「$a$ を中心とする半径 $r$ の範囲」を表す。中心 $2$、半径 $3$ なので、範囲の幅は $2r = 6$、含まれる整数は $6+1 = 7$ 個。中心が整数なら、この数え方がそのまま使える。

問 10

不等式 $3 \leqq |x| \leqq 5$ を満たす整数 $x$ は全部で コ 個ある。

正解　⑥ 6

着眼点

絶対値が $3$ 以上 $5$ 以下ということは、原点からの距離がその範囲にあるということ。正の側と負の側に同じだけ現れる。

解法

$x > 0$ のときは $3 \leqq x \leqq 5$ より $x = 3,\ 4,\ 5$ の3個。$x < 0$ のときは $3 \leqq -x \leqq 5$ より $-5 \leqq x \leqq -3$、すなわち $x = -3,\ -4,\ -5$ の3個。合わせて6個なので コ＝6。

検算

条件を満たす整数を書き出すと $-5,\ -4,\ -3,\ 3,\ 4,\ 5$ の6個。$x = 2$ は $|2| = 2$ で $3$ 未満、$x = 6$ は $|6| = 6$ で $5$ 超なのでいずれも外れる。境界の確認も合う。

つまずきやすい点

正の側だけを数えて3個と答える誤りが多い。絶対値の条件は原点について対称なので、$0$ が範囲に入らない限り個数は必ず偶数になる。答えが奇数になったら数え落としを疑うこと。

関連して押さえる

この範囲は数直線上で、原点をはさんで左右に離れた2つの区間になる。$3 \leqq |x|$ は原点から遠い条件、$|x| \leqq 5$ は近い条件で、両方を満たす部分が残る。2つの条件の向きが逆である点が、この問題の骨組みである。
